# Project design guidance

The user wants a consistent shared design throughout the portal. Before changing a page, consult `docs/portal-design-guidelines.md` and reuse the existing app shell and shared components where appropriate. Treat the current employee directory and its subdued gray table colors as the approved reference for internal data-heavy pages. Make incremental, scoped changes and preserve functionality and accessibility.

The home page and login page have separately approved designs: preserve their existing layouts and identity unless the user specifically asks to change them. For ordinary employee-facing content, respect the previously documented service-location scope; HR management operates across the organization. See `docs/location-scope.md`.

For current page status, outstanding checks, and decisions, consult and update `docs/project-progress.md` as work progresses. Older phase documents may contain historical information.
